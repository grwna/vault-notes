## 1. Summary 
- Algorithms that uses basic array, generally relying on indexing to operate on the input.
- Has $O(n)$ time complexity.

## 2. Array Algorithms 
### Two Pointers
- Uses 2 pointers, tipically starting at each edge of the array.
- Pointers move towards each other, in the opposite direction.
### Sliding Window
- Uses 2 pointers, tipically starting at the beginning.
- Pointers move in the same direction, together (fixed window), or independently (variable window sizes)
