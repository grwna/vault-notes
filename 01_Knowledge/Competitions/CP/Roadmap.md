**TL;DR:** Since you already possess foundational knowledge, your focus transitions from _learning theory_ to _pattern recognition and implementation speed_. Transitioning your passive knowledge into active solver skills typically takes **3 to 6 months** using a targeted topic-wise practice strategy.

## Phase 1: Reactivation & Implementation Mechanics (Weeks 1–4)

- **Objective:** Convert theoretical awareness into muscle memory and fast implementation without reference material.
- **Core Focus:**
    - **Implementation Drill:** Two Pointers, Sliding Window, Prefix Sums, Binary Search on Answer, and Coordinate Compression.
    - **Math & Bit Manipulation:** GCD/LCM, Modular Arithmetic, Fast Exponentiation, Bitwise operations/masks.
- **Practice Strategy:**
    - Solve 3–5 problems daily on **Codeforces** (Rating 1000–1200) or **CSES Problem Set** (Introductory Problems section).
    - Enforce a 30-minute timer per problem. If stuck beyond 30 minutes, read the editorial line-by-line until you catch the main trick, close the editorial, and implement the solver from scratch.

## Phase 2: Core Solver Patterns (Weeks 5–12)
- **Objective:** Master greedy proofs, structural graph traversal, and basic dynamic programming paradigms.
- **Core Focus:**
    - **Graphs & Trees:** BFS/DFS, Cycle Detection, Topological Sort, Dijkstra, Disjoint Set Union (DSU), Tree DP fundamentals.
    - **Dynamic Programming:** Knapsack variants, Longest Common Subsequence (LCS), Interval DP, Bitmask DP basics.
    - **Data Structures:** Monotonic Stack/Queue, Segment Trees (Point Update, Range Query).
- **Practice Strategy:**
    - Use **CSES Problem Set** (Sorting & Searching, Graph Algorithms, Dynamic Programming).
    - Filter **Codeforces** problemsets by tag and difficulty (Rating 1300–1500).
    - Solve problems in topic blocks (e.g., spending an entire week exclusively on Graph/DSU problems to build intuition).

## Phase 3: Contest Simulation & Upsolving Routine (Weeks 13–24)
- **Objective:** Handle time pressure, build edge-case awareness, and eliminate contest stress.
- **Core Focus:**
    - Virtual contests (Codeforces Div. 2 / Div. 3, AtCoder Beginner Contests).
    - Debugging strategies: generating stress-test scripts with random test generators when getting `Wrong Answer`.
- **Practice Strategy:**
    - Participate in 2 live or virtual contests per week.
    - **Strict Upsolving Rule:** After every contest, solve the first problem you failed to solve during the contest (Problem $X$) and the one immediately after it (Problem $X+1$).

## Daily Practice Structure (1.5 – 2 Hours)

```
[20 min] Warm-up / Active Recall
  └─ Implement a data structure or algorithm from scratch (e.g., DSU, Segment Tree, Dijkstra)

[60 min] Targeted Problem Solving
  └─ Attempt 2 problems at your target rating (+100 to +200 above your comfortable level)

[20 min] Post-Mortem & Editorial Review
  └─ Analyze time/space complexity, compare your solution against top-rated submissions
```
