**TL;DR:** Since you have a 25-page Team Reference Document (TRD) covering implementation-heavy C++ code snippets, **you do not need to memorize implementation details**. Your goal over the next 3 weeks is to build fast **pattern recognition** so you can identify _which_ TRD code snippet to copy-paste or adapt, and understand how to transform raw problem descriptions into algorithmic constraints.

Below is your strategic focus map tailored specifically for your contest TRD.
## 1. High-Yield Topics (Focus Here First)
These appear in almost every contest and account for the easiest 3–5 problems on a set:
- **Prefix Sums & Two Pointers / Sliding Window (TRD §5.8):**
    - **What to learn:** Recognizing monotonic properties (e.g., as right endpoint increases, left endpoint only moves right).
    - **TRD Cheat Code:** Use the provided sliding window template for subarray count/minimum bounds directly.
- **Binary Search on Answer (TRD §5.4, §5.12):**
    - **What to learn:** Identifying monotonic check functions (e.g., "Is it possible to partition $A$ into $K$ parts with max sum $\le X$?").
    - **TRD Cheat Code:** Use `first_true` or `split_array` directly from page 15 & 17.
- **Basic Graph Traversals (BFS / DFS & Grid Graphs) (TRD §7.13):**
    - **What to learn:** Mapping grid problems or state-transitions to graphs.
    - **TRD Cheat Code:** Copy $0$-$1$ BFS or standard BFS templates on page 23.
- **Disjoint Set Union (DSU) & Kruskal's MST (TRD §3.2, §7.1):**
    - **What to learn:** Problems involving "connecting components", merging sets, or offline query processing.
    - **TRD Cheat Code:** Use `DSU` on page 4 and `mst_kruskal` on page 20.

## 2. Moderate-Yield Topics (Focus on Conceptual Triggers)

## 4. 3-Week Execution Plan

### Week 1: Core Mechanics & TRD Familiarization

- **Goal:** Practice 15–20 problems on Codeforces (Difficulty 1000–1300) or CSES.
- **Focus:** Read a problem, identify the TRD section needed, and practice typing/adapting the exact TRD snippet into your code editor.
### Week 2: Intermediate Algorithms & DP Transitions

- **Goal:** Practice 10–15 problems on Codeforces (Difficulty 1200–1500) covering Binary Search on Answer, Graph BFS/DFS, DSU, and Knapsack/LIS.
- **Focus:** Build state transition logic rather than implementation logic.
### Week 3: Mock Contests & TRD Navigation
- **Goal:** Run 2–3 virtual Div. 2 / Div. 3 contests with your TRD document open.
- **Focus:** Time management, quick code assembly using your template header (Fast I/O on page 2), and edge-case testing using integer bounds/constants on page 2.
