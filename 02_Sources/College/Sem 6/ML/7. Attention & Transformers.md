# Attention
## Concept
Intermediate encoder states are reused, so its not compressed into a hidden state.

In traditional RNN with Enc-Dec, only the final hidden state $h$ of the encoder is taken into the decoder. This is a bottleneck (the decoder has so little information).

However, attention can still work even without encoder-decoder.

## Plain RNN Architecture with Attention
**Many to One with Attention**

$c$ = context vector
$$c=\sum^{N_{x}}_{j=1}a_{j}h_{j}+b_{j}$$
$N_{x}$ = number of X
$a_{j}$ = attention weights (how important one hidden state is) 
$h_{j}$ = hidden state
- the bias is optional
- Attentions are calculated using softmax to get a probability distribution

$\text{Params}= n_{\text{timestep\_enc}}+n_{hidden}$
Depicted here, assume that the output of $a_{j}h_{j}$ is a vector. The sum operation for context vector will be element wise vector addition.

**Many to Many**
$$c_{t}=\sum^{N_{x}}_{j=1}a_{tj}h_{j}+b_{j}$$
$\text{Params}= (n_{\text{timestep\_enc}}+n_{hidden})n_{\text{timestep\_dec}}$
In essence: multiple context vectors based on timestep

## Bahdanau vs Luong
The examples and explanations given above are for traditional seq2seq architecture. Modern attention mechanism are different.
### The Main Differences
**When Attention is Calculated**
- Bahdanau: *Proactive*, decoder takes information from encoder (context vector) before updating the decoder's hidden state.$$s_{t-1} \rightarrow \alpha_t \rightarrow c_t \rightarrow s_t$$
- Luong: *Reactive*, updates hidden state ($s_{t}$), then use that to calculate attention and context vector.$$s_t \rightarrow \alpha_t \rightarrow c_t \rightarrow \tilde{s}_t$$
**How Alignment Scores are Calculated**
- Bahdanau: *Additive*$$\text{score}(s_{t-1}, h_j) = v_a^T \tanh(W_a s_{t-1} + U_a h_j)$$
- Luong: *Multiplicative* $$\text{score}(s_t, h_j) = s_t^T h_j$$

Fig *Visualization of Key-Query-Value with Attention*
![[Pasted image 20260607094658.png|400]]

KQV are the main idea of self attention. KQV are matrices derived from the same sentence embeddings, which are multiplied by $W_{K/Q/V}$, weight matrices unique to each K, Q, or V.

- $Q$ - query
	- "I'm generating the $t-$th word, what information do i need?"
	- Equivalent to Decoder's hidden state
- $K$ - key
	- Label/index of available information, the answer to query
	- Equivalent to Encoder's hidden state
- $V$ - value
	- The value being extracted
	- Equivalent to Encoder's hidden state

**Single-head attention**
Uses Queries, which are multiplied with transpose of Keys, to produce *attention pattern* (See figure above, the purple-white circles). Then this is multiplied with the Values. For accuracy, "*Attention is all you need*" divides the Query-Key result with the sqrt of Key-Query matrix dimension. 
$$\text{Attention}(Q,K,V)=\text{softmax}\left( \frac{QK^T}{\sqrt{ d_{k} }} \right)V$$
$d_{k}=\text{context\_size}^2$
$$d_{k}=\frac{d_{\text{model}}}{h}$$
$d_{\text{model}}$ = model dimension
$h$ = number of heads

**Multi-head attention**
Made up of many single-head attention. Each head processes the same data with different *weights*. This allows the model to project the data to multiple representation subspaces, which allows for many relationship detection. 

The different weights are obtained through training with different random initialization.

**Masking**
To prevent later tokens influencing earlier tokens, a masking is applied:
- Before softmax, change to negative infinity
- After softmax, their values will be zero
