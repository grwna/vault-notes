# What & Why
- No supervision, only reward signal
- Time matters -> past affect future
- Feedback can be delayed
- Indirect feedback
- When direct supervision is not available

**Supervised vs Reinforcement**
Supervised
- Told the correct answer/what to output
- Uses cost function (how far the output from the correct output)
Reinforcement
- No dataset of correct answers
- Uses reward function (evaluates quality of each action)
- Evaluates how good an action is (towards the goal), not what the action should have been

**Reward Hypothesis**
>Any goal can be formalized as the outcome of maximizing a cumulative reward

# Core Concepts
- Agents & Environment
	- Agents do things to environment.
- Rewards
	- Agent maximizes cumulative reward
	- $G_{t}=R_{t+1}+R_{t+2}\dots$
	- $G_{t}$ - the return
- Value
	- Expected cumulative reward at state $s$
	- $v(s)=\mathbb{E}[G_{t} \vert S_{t}=s]$
	- $G_{t}=R_{t+1}+G_{t+1}$ -> recursive definition of return
- Actions
	- Select actions to maximize value
	- May be better to sacrifice immediate reward to gain more long-term reward.
		- Financial investment
		- Defensive game movement
- Action Values
	- Condition values on actions
	- $q(s,a)=\mathbb{E}[G_{t} \vert S_{t}=s, A_{t}=a]$

**Agent Components**
- Agent State
	- Action depends on state (agent and environment may have states)
	- Agent may not know full state of environment
	- History can be used to construct agent state
	- Full observability: observation = environment state: $S_{t}=O_{t}$
	- History is a sequence of observations, action, rewards:
	- $H_{t}=O_{0}, A_{0}, R_{1}, O_{1},\dots,O_{t-1}, Q_{t-1}, R_{t}, O_{t},$
- Policy
	- A mapping from states to actions
	- Defines agent's behaviour
	- Deterministic policy: $A=\pi(S)$
	- Stochastic policy: $\pi(A\vert S)=p(A\vert S)$ 
	- **In essence**, policy is what the agent thinks is the best action to take
- Value function
	- The expected return. 
	- $v(s)=\mathbb{E}[G_{t} \vert S_{t}=s, \pi]$
	- $v(s)=\mathbb{E}[R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3} + \dots \vert S_{t}=s, \pi]$
	- $\gamma =$ discount factor $[0 - 1]$ : trades off importance of immediate vs long term rewards
	- Value depents on policy
	- Can be used ot evaluate desirability of states (selecting actions)
	![[Pasted image 20260608182502.png|500]]
- Model
	- Optional: agent may or may not have a model
	- Predicts what environment will do next
	- Predicts next state:
		- $\mathcal{P}(s,a,s^`)\approx p(S_{t+1}=s^`\vert S_{t}=s, A_{t}=a)$
	- Predicts next immediate rewards:
		- $\mathcal{R}(s,a)\approx \mathbb{E}[R_{t+1}S_{t}=s, A_{t}=a]$
	- A model does not immediately give good policy, we still need a good plan

**Exploration vs Exploitation**
Off-policy vs On-policy
- Exploitation (on-policy): play it safe (pick the agent's best policy)
- Exploration (off-policy): Try other action to gain more information (the action can be good, can be bad, and can be the actual unknown best action)

> Something youre familiar with, and recognized as the best, may not actually be the best.

# Temporal Difference Learning 
**Core Idea**
- Does not need to wait until we get Return, Monte carlo does
	- Can learn from incomplete sequences of observations
- Idea:
	- Apply TD to $q(s,a)$
	- Update every time-step
